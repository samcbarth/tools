UTM builder

Paste a page URL, fill in source, medium and campaign, and copy a tagged link that GA4 and HubSpot can attribute.

Runs entirely in your browser. Nothing you type, paste or open here is uploaded to any server.

How do I build a UTM link?

Add utm_source, utm_medium and utm_campaign to the end of your page URL as query parameters, all in lowercase. This tool does it for you: fill in the fields and copy the result.

  1. Paste the landing page URL into Website URL.
  2. Enter where the click comes from in Campaign source, for example linkedin or newsletter.
  3. Enter the type of traffic in Campaign medium, for example email, social or cpc.
  4. Name the campaign, then add term or content only if you need to split results further.
  5. Copy the tagged URL and use it in your post, email or ad.

Examples

LinkedIn post for a product launch

Input

URL: https://example.com/pricing
Source: linkedin
Medium: social
Campaign: spring launch

Result

https://example.com/pricing?utm_source=linkedin&utm_medium=social&utm_campaign=spring-launch

Two buttons in one email

Use utm_content to tell links in the same email apart, for example hero-button and footer-link. Source, medium and campaign stay the same so the email reports as one campaign.

Frequently asked questions

Which UTM parameters are required?

GA4 needs utm_source and utm_medium to place a visit in a channel. utm_campaign is strongly recommended. utm_term, utm_content and utm_id are optional.

Should UTM values be lowercase?

Yes. Analytics tools treat Email and email as different values, so mixed case splits your reports. The tool lowercases by default.

Can I put UTM links on my own website?

No. Tagging internal links starts a new session and overwrites the original source, so a visitor from Google can end up credited to your own banner. Use UTMs only on links from outside your site.

Does this work with HubSpot?

Yes. HubSpot reads the same UTM parameters on page views and form submissions, and its own tracking URL builder produces the same format.

What happens if the URL already has a query string or #anchor?

The tool keeps existing parameters and the anchor, and replaces only UTM parameters you fill in.
