CSV cleaner and dedupe tool

Open or paste a CSV, choose a column to dedupe on (email is picked automatically), and download a clean file ready for import.

Runs entirely in your browser. Nothing you type, paste or open here is uploaded to any server.

How do I remove duplicates from a CSV file?

Pick the column that identifies a record, usually email, and keep only the first row for each value, ignoring case and extra spaces. Open your file here, choose that column, and download the cleaned CSV.

  1. Paste the CSV or open the file. The delimiter is detected automatically.
  2. Choose the column to dedupe on, or Whole row.
  3. Keep trim, empty row removal and case-insensitive matching on.
  4. Check the counts and the preview table.
  5. Download the clean CSV. It opens in Excel with accents intact.

Frequently asked questions

Is there a file size limit?

Only your device's memory. Files with tens of thousands of rows are fine on a normal laptop.

Which duplicate is kept?

The first one in the file. Sort the file first if you want to keep, for example, the most recent record.

Does it change my original file?

No. You get a new download. The original file on your computer is not touched.

Why do accents look wrong when I open the result in Excel?

The download includes a byte order mark so Excel reads it as UTF-8. If you copy and paste instead, use Excel's Data, From Text/CSV import and pick UTF-8.
