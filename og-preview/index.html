How do I check my Open Graph tags?


Paste your page's HTML head here, or type the tags, and the tool shows the link card plus warnings for missing or oversized values. A good card has an og:title under about 70 characters, a 1200 x 630 pixel og:image, and an absolute og:url.


  1. Choose Paste page HTML and paste the source of your page, or type the values directly.
  2. Look at the large and small card previews.
  3. Fix anything marked Fix or Check in the list.
  4. Copy the generated tags into your page's head.
  5. After publishing, re-scrape the URL in each platform's own debugger so it drops its cached card.

Frequently asked questions


What size should an og:image be?
1200 x 630 pixels (a 1.91 to 1 ratio) works for large cards on most platforms. Keep text away from the edges, since some platforms crop.
Why does my old image still show after I changed it?
Platforms cache link cards. Use the platform's own sharing debugger or post inspector to request a fresh scrape.
Can this tool fetch my live page?
No. Browsers block one site from reading another site's HTML, and this tool never routes your URL through a server. Paste the HTML from View Source instead.
Does X (Twitter) use Open Graph tags?
X reads its own twitter: tags first and falls back to Open Graph for title, description and image. A twitter:card tag sets the card size.
