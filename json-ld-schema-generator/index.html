JSON-LD schema generator

Pick a schema type, fill in the fields you have, and copy a ready-to-paste JSON-LD script tag. Empty fields are left out automatically.

Runs entirely in your browser. Nothing you type, paste or open here is uploaded to any server.












How do I add schema markup to my page?


Create a JSON-LD script with the schema.org type that matches your page, then paste it into the page's HTML. This tool builds that script from a form so you do not have to write the JSON by hand.


  1. Choose Local business, Article or Product.
  2. Fill in the fields. Required ones are marked.
  3. Copy the code.
  4. Paste it into the head or body of the matching page, or into your CMS's header HTML setting for that page.
  5. After publishing, run the page through Google's Rich Results Test and the Schema Markup Validator.

Frequently asked questions


Does schema markup improve rankings?
Google says structured data helps it understand a page and can make the page eligible for rich results. It is not described as a direct ranking boost.
Should I add a rating to Product schema?
Only if the page shows real reviews from customers. Marking up ratings that are not visible on the page breaks Google's structured data guidelines.
Where does JSON-LD go in HubSpot?
In HubSpot, add it to the page's Settings, Advanced, Head HTML, or to a module in the template if every page of that type needs it.
Can I have more than one schema block on a page?
Yes. Pages often carry several, for example BreadcrumbList plus Article. Each should describe content that is on the page.
